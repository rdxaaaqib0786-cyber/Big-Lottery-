# Big Lottery Dashboard Starter

Starter project for an Android student dashboard and a responsive web admin panel for course management.

## Web panel
Open `web-admin/index.html` in a browser. Demo data is held in browser memory and resets on refresh.

## Android
Open this folder in Android Studio, sync Gradle, then use Build > Build APK(s).
This is a starter UI and has not been compiled/device-tested here.

## Production checklist
Add secure authentication, role-based permissions, API/backend, database, file storage, backups, audit logs, and privacy controls before deployment. This project includes no real-money betting, deposits, or withdrawals.
